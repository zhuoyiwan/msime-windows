## 6. 如何更新本文档

```powershell
# 1) 拉取 open issue（GitHub REST API，未认证时限流 60 次/小时）
$h = @{ 'User-Agent' = 'codex-agent'; 'Accept' = 'application/vnd.github+json' }
$all = @()
for ($p = 1; $p -le 6; $p++) {
  $r = Invoke-RestMethod -Uri "https://api.github.com/repos/metasequoiaime/msime-windows/issues?state=open&per_page=100&page=$p" -Headers $h
  if ($r.Count -eq 0) { break }
  $all += $r
  if ($r.Count -lt 100) { break }
}
# 2) 过滤 PR，按标签/主题重新归类后更新本文件
$all | Where-Object { $_.pull_request -eq $null } | Select-Object number, title, labels
```
