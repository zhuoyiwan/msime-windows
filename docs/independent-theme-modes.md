# 独立深浅主题

外观页的主题模式默认展开，各界面分别支持 `follow`（跟随全局）、`system`（独立跟随设备）、`light`、`dark`。全局深色时，设置界面仍可独立跟随设备；候选窗、工具栏和各面板也可分别选择。既有 follow 的含义保持不变。

后端的配置读取、写入与原生主题解析都接受 system；设置页预览与文档配色使用同一规则，并监听设备模式变化。出厂与开发配置模板明确列出该值，既有设置进程的字段映射继续读写这些键。壁纸取色按每个界面最终解析的模式使用原有配色。

验证：独立 system 保存重载、非法值拒绝、原生解析与全局覆盖隔离进入 Server 测试；页面覆盖独立 system 与运行期设备主题变化。原生构建、Server 测试和设置页生产构建通过，最终包与设备目视验收另行记录。

本轮 Windows Server 678 项测试、68 份共享 fixture、全部 146 项设置页测试、安装文件收集契约和 clang-format 18.1.8 检查通过。完整未签名包 r8 已编译，未运行安装程序或修改本机防火墙。Android r5 的软件与键盘皮肤同样分开，API 28/35 的独立模式组合与实际键盘深浅显示通过。
