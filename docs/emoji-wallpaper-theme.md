# Emoji 候选与壁纸配色（zhuoyiwan 改版）

普通拼音候选默认带 Emoji。输入 `sikao` 或 `si'kao` 时，🤔 紧跟「思考」，选中后消费整个拼音输入。支持现有词库中的其他表情和双拼；Android 九键仍使用既有读法混排。Windows 的选项在「工具 → 混输 → emoji 混输」，Android 在「输入 → 智能 → 候选带 emoji」。首次升级开启一次，之后保留用户关闭的选择。

Windows 在「外观 → 主题模式 → 壁纸取色」开启，候选、悬浮工具栏、托盘菜单和设置页使用同一套配色。取首个显示器静态壁纸的主色，生成柔和的明暗色阶；路径与修改时间不变时复用结果，每十秒检查一次。它使用本地色阶推导，与 Android 系统 Monet 算法不同。不可读取的动态壁纸或纯黑白壁纸使用稳定回退，不修改系统壁纸、系统主题或皮肤文件。关闭恢复原皮肤，现有的明暗设置继续有效。

Android 在「应用主题 → 壁纸取色（Monet）」选择。Android 12 及以上使用系统 Monet 色板，旧系统使用公开的 WallpaperColors 主色及 Material 色彩角色，无法读取时回退。应用与「跟随系统」键盘共用种子；用户自定义键盘皮肤保留。壁纸颜色更新时设置界面刷新，键盘在新输入会话或最多一分钟的主题检查时刷新。

壁纸只在本机解析，不上传、不参与剪贴板同步，也不请求照片或存储权限。
