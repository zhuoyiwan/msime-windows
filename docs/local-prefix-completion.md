# 本机词条前缀补全与安卓横屏布局

本地改版：Windows r6 / Android r4（2026-10-12）。两端分别录入词条，不通过局域网剪贴板共享词库。

## 使用

- 安卓：设置 → 本地数据 → 前缀补全。添加完整姓名、手机号或身份证号；点词条可设置字母缩写，例如 `csxm`。输入 `cs` 或号码前三位后点候选输出全文。与本机常用语共用正文，密码与隐私输入框不显示补全。
- Windows：设置 → 实用功能 → 快捷短语。姓名可保存字母缩写；号码用完整号码作为编码与正文。开启“快捷短语混入候选”及候选混输总开关。字母按编码前缀匹配；纯数字至少三位出现补全，首选始终是原样数字，点击后面的词条输出全文。
- 安卓：设置 → 键盘 → 数字键盘排列，支持电话式、聊天常用、计算器式、横排及自定义数字顺序；常用符号排列可编辑两行，每行 4–10 个键。

## 处理范围

安卓根据当前窗口的测量约束和配置高度压缩键区，优先保留读音、候选与导航。用户保存的高度不被改写，回到竖屏恢复；补上输入视图冷启动期间收起后再次弹出的会话启动任务。设备测试发现的数字布局设置读取类型错误已修复，设置页和键区均按 CHOICE 读取。

前缀补全只使用手动保存词条，不采集通讯录或自动学习号码。Windows 通过 Worker 消息 34 同步十位数字首位掩码；正文不在配置消息中传递。数字键在数字组字时继续输入，原样数字支持空格或回车；数字补全不参与云候选查询。词条修改、配置和方案切换更新掩码，断线清空。

## 验证

- Windows Server 全套 ctest、32/64 位 TSF 各 12 项测试通过；设置页 144 项测试通过。新增合成号码、姓名缩写、数字起头和继续输入规则的回归。
- 安卓编译与 lint、前缀/布局/高度/视图恢复 JVM 测试、设置搜索索引检查通过。
- API 35 模拟器在 1080×1920 与 720×1280、320 dpi 下验证完整号码和姓名补全、无重复前缀、密码排除、数字预设和自定义符号、最大键高横屏候选点击上屏、收起重开与竖屏恢复。
- API 28 实际点选手机号补全成功，但跨编辑器与旋转批量测试未完整通过，观察到旧无障碍节点及冷启动先直接输入的现象；Android 9 稳定性仍需继续追查，未标为完整验收通过。

QQ 与厂商游戏小窗仍需真机复测：模拟器覆盖标准横屏与受限屏幕尺寸，未安装火影忍者和 QQ。

安装包位于 `installer/Output/`：Android 为同一证书签名的 arm64-v8a APK（code 3004）；Windows 为本地未签名包 r6。
